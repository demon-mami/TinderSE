# TinderSE

iPad向けの短音源・厳選用Webツールです。

- タップ: 即時試聴（前の音は停止）
- 採用: 各カードの採用ボタン
- 状態保存: ブラウザのlocalStorage
- 結果出力: 選択済み音源だけCSV
- CSV読込: 選択状態の復元 / 追加

## 音源整理ルール

- 原本154 WAVから完全一致重複1件を除外し、153件を使用
- 先頭は実質無音のみ除去（アタック保護）
- 後端は 10 ms RMS が最大RMS比 -42 dB以下、40 ms継続、以後に有意な回復なし、残存エネルギー0.1%以下をAND判定
- 上記より前に終端が得られない場合は130 msを上限としてカット
- 130 ms強制カット時は末尾1 msに極短Raised-Cosine fade-out
- 元のSample Rateを保持、Stereo / PCM 24-bitで出力

`mapping.csv` に元ファイル名と整理後ファイル名の対応を保存しています。
